## 📌 About This Site

This site is designed to be **lightweight, editable, and scalable**. Tables are written in Markdown and rendered by Jekyll. More categories and tools will be added over time!

Want to contribute or request a table? [Submit an issue on GitHub](https://github.com/YOUR-USERNAME/dnd-tables-site/issues).
